# ZeroSearch

A dependency-free local search engine built from scratch using C++ standard library.

## About

ZeroSearch is a local document search engine designed to index documents,
store an inverted index, and return relevant search results without relying
on third-party runtime dependencies.

## Goals

- Fast document indexing
- Efficient search
- Inverted index
- TF-IDF / BM25 ranking
- Persistent storage
- Zero third-party runtime dependencies
